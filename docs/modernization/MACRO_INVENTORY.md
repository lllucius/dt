## Classification by category

### Current platform

- `__linux__`: compiler/platform macro used throughout Unix-like runtime paths.
- `_UNIX_LIKE_`: internal Unix-like path in API and multi-language runtime code.
- `_REENTRANT`: Linux build-system define for threaded code.
- `NOMME`: Linux build-system define selecting non-MME behavior.
- `HAVE_ICONV`: generated by `configure` when iconv is available.
- `USE_ALSA`: current optional Linux audio define when ALSA development files
  are found.
- `USE_PULSEAUDIO`: current optional Linux audio define when PulseAudio simple
  development files are found.
- `DISABLE_AUDIO`: build-system option when `./configure --disable-audio` is
  used.

### Current architecture

- No x86_64-specific project macro was observed in the Phase 1 Linux build.
- `OS_SIXTY_FOUR_BIT` is present in OSF-oriented code and needs deeper review
  before reuse or removal.
